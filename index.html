The rover

Four TT gear motors, an Arduino Nano with two DRV8833 drivers and an ESP32-CAM, in a printable open-frame chassis. The OpenSCAD source is in the repo.

The physics

MuJoCo runs in the page as WebAssembly. Speed, skid-steer turning, wheel slip and pushing the ball all come from its contact solver, stepped at 50 Hz.

Embed it

The simulator is a static page you can frame anywhere, with a small message API for your own buttons. See the embedding guide.
